🚀 Quick GitHub Pages Deployment
1. Folder Structure: 
birthday-surprise/
├── index.html        (Save this code file)
├── images/           (Drop photos: photo1.jpg, photo2.jpg...)
└── music/            (Drop her song: song.mp3)
2. Create GitHub Repo:

Go to github.com/new, name it birthday-surprise, select Public, and click Create.

3. Drag & Drop Files:

Click "uploading an existing file", drag the index.html, images folder, and music folder, then commit.

4. Turn on GitHub Pages:

Go to Settings → Pages → Under Branch select main / root → Click Save.

✨ Your link will be live at:
https://yourusername.github.io/birthday-surprise/
